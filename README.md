# **Keybindings**
## Основная клавиша (Mod) — SUPER (Windows Key).
🖥️ Система и Приложения
```
Действие	            Клавиши          	      Описание
Терминал              Super + Q	              Открыть Kitty
Файлы                 Super + E	              Открыть Thunar
Меню приложений	      Super + R	              Открыть Rofi (Launcher)
Браузер	              Super + B	              Открыть браузер (если настроено)
Закрыть окно	        Super + C	              Убить активное окно
Выход из Hyprland	    Super + M	              Разлогиниться
```
## Управление окнами
```
Действие	            Клавиши	                Описание
Переключить окно	    Alt + Tab	              Меню открытых окон
Фокус	                Super + ← ↑ ↓ →	        Перемещение фокуса
Двигать окно	        Super + Shift + Стрелки	Переместить окно
Плавающий режим	      Super + V	              Сделать окно плавающим
Свернуть все	        Super + D	              Показать рабочий стол
Воркспейсы	          Super + 0-9	            Переключить рабочий стол
Перенести окно	      Super + Shift + 0-9	    Отправить окно на стол
```
## Утилиты и Инструменты
```
Действие	            Клавиши	                 Описание
История буфера	      Super + Shift + V	       Меню скопированного текста
Пипетка (Цвет)	      Super + Shift + C	       Скопировать цвет пикселя
Блокировка	          Super + L	               Заблокировать экран (Hyprlock)
Меню выхода	          Super + Esc	             Выключение / Перезагрузка (Wlogout)
```
## Скриншоты
```
Действие	           Клавиши	                 Куда сохраняется
Весь экран	         PrintScreen	             В файл ~/Pictures/Screenshots
Область	             Super + Shift + S	       В буфер обмена (Ctrl+V)
Область (Файл)	     Shift + Print	           В файл
```
## Медиа
```
Громкость: Кнопки громкости на клавиатуре
Яркость: Кнопки яркости
Плеер: Кнопки Play/Pause/Next
```
